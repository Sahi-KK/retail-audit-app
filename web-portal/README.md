# Retail Audit Enterprise Web Portal

A high-performance, standalone web application for retail auditing, built with Vite, React, and Tailwind CSS.

## Getting Started

1.  Navigate to the directory:
    ```bash
    cd web-portal
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Launch the development server:
    ```bash
    npm run dev
    ```

## Technology Stack
- **Framework**: React 18
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **State Management**: Zustand (with Persistence)

## Architecture
This portal shares the same data structures (`auditQuestions`, `locationData`) and state logic as the mobile app but is optimized for desktop and mobile browser performance.
