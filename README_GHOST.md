# 🕵️‍♂️ Retail Audit: Ghost Developer Mode

Your app is now managed entirely in the cloud. You do NOT need any heavy developer tools or gigabytes of storage on your Mac.

### 📱 Where is my App?
Your standalone APKs are built automatically every time a change is made.
1.  Go to: [github.com/Sahi-KK/retail-audit-app/actions](https://github.com/Sahi-KK/retail-audit-app/actions)
2.  Click the most recent **✅ Success** build.
3.  Scroll to **Artifacts** and download the `retail-audit-apk`.

### 🛡️ How to request changes
Just tell me "Ghost: [Your Request]" (e.g., *"Ghost: Change the button color to Blue"*).
1.  I will change the code.
2.  I will "Push" to the cloud for you.
3.  GitHub will build the updated APK.
4.  You just download and install.
